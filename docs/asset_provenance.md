The InvISP checkpoint and ELD calibration match copies already present in RawPointNet byte for byte. The official MagicLeap checkpoint replaces that project's TensorFlow-converted checkpoint. MagicLeap's `LICENSE` restricts its software and weights to noncommercial academic research. Third-party repositories and weights remain in the ignored `third_party/` directory; `scripts/fetch_assets.sh` fetches and verifies them.

The Canon InvISP checkpoint receives `[0,1]` sRGB and its inverse output corresponds to gamma-compressed, white-balanced 12-bit Raw. Following the bridge used in RawPointNet, `rawfeat.sensor.invisp_to_sensor_rgb` inverts gamma 2.2 and the Canon white balance `[2020,1024,1458] / 2020`, maps the 12-bit signal to the 14-bit EOS 5D4 range `[2048,16383]`, then clips the clean sensor signal to that calibrated range. The ELD path uses the prior projects' full sensor-DN exposure sequence, the official EOS 5D4 calibration's `Kmin`, `Kmax`, Tukey read, row, and quantization parameters, and no clipping after noise. Ratio 1 still samples ELD noise. The student subtracts black once, divides by `16383-2048`, applies the same Canon white balance, and packs fixed RGGB as `[R,G1,G2,B]`. The full-resolution clean gray target uses the corresponding linear normalized three-channel sensor image before Bayer sampling. The MeanAD baseline instead follows Raw-SLAM's separate `/16383` and uint16 path.

The EOS 5D4 calibration file has no black or white fields; 2048 and 16383 are the verified values in Raw-SLAM's Canon synthesis bridge. The original InvISP source checkpoint contains 16 unused ActNorm tensors absent from its published model definition. The loader accepts precisely those extras and requires all actual model weights to match.

On 2026-10-02, bounded CUDA measurements on PyTorch 2.12.1+cu130 found correlations between Poisson and subsequent noise terms sharing a generator. `CanonELD.apply` now retains the original Poisson seed and parameter sampling, and derives independent read/row/quantization seeds using `np.random.SeedSequence([seed,1])`. The camera calibration, full-DN exposure model and sensor mapping are unchanged. The old source, cache and baseline remain preserved; regenerated noise cases use cache identity `d950a2368a67a363bf28ed8fe91029974eac05ede17225020d5fe2c0c0b1757d`. `configs/formal.yaml` points to the matching cache and full baseline under `outputs/checks/detection_followup_20261002/`, whose score is 65.60296854%. See the [measured follow-up report](detection_followup_report_20261002.md) for the reproduction, limited causal interpretation and budget; formal training was not started.
