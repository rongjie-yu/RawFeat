## 1. 目标与范围

训练一个直接接收 Bayer Raw 的单一整体网络，在低光噪声下提取稳定的关键点和描述子，最终服务于在线 SLAM。

1. 输出原始 Bayer 坐标系下的关键点位置、检测分数和 128 维描述子。
2. 优化关键点重复性、定位准确性、描述子匹配精度及正确匹配数量。
3. 与 MeanAD + SuperPoint 基线对比，**目标是超过该基线**。
4. 报告参数量、MACs、实测延迟，作为对比指标，不设硬性延迟目标；设计上靠结构而非堆参数提升效率。

**评估分期**

| 阶段 | 内容 | 进入条件 |
|---|---|---|
| 1 | COCO val2017 固定子集的合成验证（本文 §9） | 本文方案实现后立即进行 |
| 2 | 合成 HPatches-raw + MID 真实数据 | 阶段 1 表现良好后（门槛待定，建议：五档主分数高于基线，且 clean 组不低于基线） |
| 3 | SLAM 集成评估 | 不在本文范围 |

不在本文范围：LightGlue、词典、回环、二值描述子、INT8、FP16。

降噪由共享网络学习，不采用独立降噪器与提取器级联。训练期的辅助灰度头只提供降噪引导，部署时删除。

## 2. 总体流程

### 2.1 训练

```text
COCO sRGB
  → 保持宽高比缩放、尺度变化、裁剪
  → 两个视角独立抽取一种 sRGB 外观操作
  → 每个视角在线执行冻结的 InvISP，得到 clean 三通道线性 Raw
  → 同一视角的 sRGB 与 clean Raw 应用相同几何变换
      ├─ sRGB 灰度 → 冻结的 SuperPoint 教师 → 检测软目标
      └─ clean Raw
          ├─ 线性灰度 → 辅助灰度目标
          └─ Bayer 采样 → ELD 噪声与曝光归一化 → 四通道打包
                → 学生共享骨干
                    ├─ 检测头
                    ├─ 描述子头
                    └─ 辅助灰度头（仅训练）
```

训练损失三项：检测蒸馏、几何匹配、辅助灰度重建。没有 clean/noisy 描述子一致性，也没有 clean 描述子分支（两个独立噪声视角上的匹配损失已强制噪声不变性）。

### 2.2 部署

```text
Raw 线性预处理 → [R, G1, G2, B] 打包 → 已融合的 RepVGG 骨干
  → 检测头和描述子头 → 关键点筛选、描述子采样、裁剪坐标恢复
```

## 3. 数据与预处理

### 3.1 数据来源与尺寸

| 项目 | 配置 |
|---|---|
| 训练集 | COCO train2017 |
| 训练期验证集 | COCO val2017 固定子集，与训练源图像不重合 |
| 原始 Bayer 尺寸 | 480 × 640 |
| 学生输入 | 4 × 240 × 320（尺寸为 8 的倍数） |
| 基础缩放 | 保持宽高比，缩放到能覆盖目标裁剪区域；基础缩放和裁剪在 sRGB 阶段完成，不拉伸 |
| 额外尺度变化 | 基础缩放倍率的 1.0–1.2 倍 |
| 裁剪 | 训练随机裁剪，验证固定裁剪 |

### 3.2 sRGB 随机外观增强

两个视角的操作类别和参数独立采样，每个视角最多一种。

| 操作 | 概率 | 参数 |
|---|---:|---|
| 保持原始外观（NoOp） | 70% | — |
| 亮度 | 5% | 因子 0.9–1.1 |
| 对比度 | 5% | 因子 0.85–1.15 |
| Gamma | 5% | 指数 0.85–1.15 |
| 饱和度 | 5% | 因子 0.8–1.2 |
| 平滑阴影（PlasmaShadow） | 5% | 强度 0.1–0.35；roughness 0.7 |
| 模糊 | 5% | 高斯、运动模糊各占一半 |

等价抽样池为"原始 × 14，其余六类各 × 1"，用权重实现。两个视角独立抽样时：49% 的图像对两边保持原样，42% 仅一边增强，9% 两边增强。

- 统一用 Albumentations（锁定版本，目标 2.0.8；接口须在实现时用单元测试核对），用 OneOf 与 NoOp 抽样，不手写增强算法。
- 高斯模糊 sigma 0.3–1.0；运动模糊核尺寸 3 或 5，角度 0–180°，`direction_range=(0,0)`，`allow_shifted=False`。像素尺度定义在进入 InvISP 的 sRGB 图像上。
- 阴影选平滑变化，减少硬边合成形状制造角点；模糊用对称居中的核，避免方向性偏移。
- 不加 sRGB 噪声、CutMix、随机擦除、通道交换、反相、额外 JPEG 压缩。传感器噪声由 Raw 域 ELD 负责。
- "保持原始外观"仍执行几何变换和 Raw 噪声合成。

### 3.3 在线 InvISP

- 每个视角的 sRGB 增强结果分别输入 InvISP，得到该视角的 clean 三通道线性 Raw。
- InvISP 冻结、评估模式、不参与反向传播；在线运行，不缓存固定输出替代随机增强。
- 教师输入与 clean Raw 必须来自同一份增强结果。教师的"干净输入"指没有传感器噪声，允许存在 §3.2 的外观增强。

### 3.4 几何变换与有效区域

| 项目 | 经验配置 |
|---|---|
| 参考视角 A | 基础裁剪坐标系（不 warp） |
| 目标视角 B | 随机仿射 + 轻度透视 |
| 旋转 / 缩放 / 平移 | ±30° / 0.8–1.2 / 各不超过图像尺寸的 10% |
| 透视 | Kornia `distortion_scale=0.15` |
| 共同有效区域 | 至少覆盖两个视角各自面积的 50%，不足则重新采样 |

- 用成熟库生成并执行变换，保存准确的变换矩阵；裁剪、缩放、warp 都计入对应关系。
- 同一视角的 sRGB 与三通道线性 Raw 用同一个几何变换。**先对三通道 Raw 做 warp，再采样 Bayer、加噪**，不直接 warp 马赛克或已有噪声。
- 有效区域掩码随几何变换传播；无效区域不参与损失；有效区域边缘收缩 8 个原图像素；检测监督只保留整个 8×8 cell 都有效的位置。

### 3.5 曝光倍率、ELD 噪声与数值域

$$x_{\mathrm{noisy}} = r\left[\,x_{\mathrm{clean}}/r + n_{\mathrm{ELD}}(x_{\mathrm{clean}}/r)\,\right]$$

ratio 越大，模拟曝光越低。两个视角独立采样 ratio，噪声也独立生成。ELD 使用实际相机标定配置，在其对应的传感器数值域生成噪声。

**逐步数值域**（实现须逐项对照并写断言；BL、WL 为合成相机的黑/白电平，Raw-SLAM 合成路径中为 2048、16383，需对照实际代码确认）：

| 步 | 操作 | 数值域与说明 |
|---|---|---|
| 1 | InvISP 输出 clean 三通道线性 Raw | 归一化线性域（0 = 黑电平；上界约定由 InvISP 输出实测确定） |
| 2 | 同一几何变换 warp 三通道，再采样 Bayer（RGGB，固定相位） | 归一化线性域 |
| 3 | 换算到传感器域：ADU = BL + x·(WL−BL) | ADU |
| 4 | 模拟低曝光：ADU_low = BL + (ADU−BL)/r | 信号除以 r，黑电平不变 |
| 5 | 加 ELD 噪声 | 按 ELD 接口约定的域（是否含黑电平以其接口为准——**最需核对的一步**） |
| 6 | 回到归一化域：x′ = (ADU_noisy − BL)/(WL − BL) | **保留负值，不裁剪** |
| 7 | 曝光归一化：x_noisy = r·x′ | 即上式 |
| 8 | 白平衡 | 沿用既定定义；是否应用及增益来源见 §17；训练与部署一致 |
| 9 | 打包 [R,G1,G2,B] | 4 × 240 × 320 |

**必须通过的断言**：
- (a) 明亮像素处 E[x_noisy − x_clean] ≈ 0（无偏，说明没有裁剪负值、没有重复减黑电平）；
- (b) 零信号像素的均值 ≈ 0，而不是 −BL/(WL−BL)；
- (c) 噪声标准差随 r 单调增大，且与 ELD 标定曲线的预期一致。

不增加非线性压缩；固定 CFA 相位；本阶段不处理随机 CFA、G1/G2 交换、绿色通道增益扰动（CFA 泛化性视实际表现再分析）。

### 3.6 辅助灰度目标

从原分辨率、完成相同几何变换与线性归一化的 clean 三通道 Raw 生成：

$$Y_{\mathrm{clean}} = 0.299R + 0.587G + 0.114B$$

灰度定义一次性固定，不通过 packed 四通道合成低分辨率目标。目标保留该视角的 sRGB 阴影、模糊等增强效果；辅助头提供传感器降噪引导，不要求撤销这些外观增强。教师输入的灰度转换与基线一致（OpenCV 的 RGB2GRAY，系数同上）。

## 4. 网络

### 4.1 共享骨干

| 阶段 | 输出尺寸 | 通道 | 块数 | 下采样 |
|---|---|---:|---:|---|
| 输入 | H/2 × W/2 | 4 | — | Bayer 打包 |
| S1 | H/2 × W/2 | 24 | 2（含 4→24 的第一块） | 无 |
| S2 | H/4 × W/4 | 48 | 3 | 第一个块步长 2 |
| S3 | H/8 × W/8 | 96 | 4 | 第一个块步长 2 |

RepVGG：训练期每个块 3×3+BN、1×1+BN，及尺寸和通道允许时的恒等+BN 分支，相加后接 ReLU；部署时融合为单个带偏置的 3×3 卷积 + ReLU。S1/S2/S3 共同完成噪声处理和特征提取，不规定某段只负责降噪。

默认不加：H/4→H/8 跳连、金字塔、大核、注意力、Transformer、Mamba、噪声条件 FiLM。其中跳连是检测头定位不足时的首选备选（§15.1，约 +88M MACs @640×480）。

参考规格（480×640，部署形态，描述子 128 维）：约 4.03 GMACs、0.595M 参数；原版 SuperPoint 为 26.05 GMACs、1.301M 参数。

### 4.2 检测头

```text
S3（96）→ 独立 RepVGG 块（128）→ 1×1 线性卷积（65）
```

输出 65 × H/8 × W/8（SuperPoint 格式：64 个像素位置 + 最后一个"无关键点"通道；通道 k 对应 cell 内 (k//8, k%8)）。推理：softmax → 移除"无关键点"通道 → 重排为原图分数图 → 边界过滤、NMS、数量筛选 → 恢复裁剪偏移。

### 4.3 描述子头

```text
S3（96）→ 独立 RepVGG 块（128）→ 1×1 线性卷积（128）
```

输出 128 × H/8 × W/8。网格描述子做 L2 归一化，在关键点位置双线性插值后再次归一化。描述子完全在学生自己的空间学习，不对齐教师。

### 4.4 辅助灰度头（仅训练）

1. S2 经 1×1 卷积降到 24 通道，上采样到 S1 尺寸；
2. 与 S1 拼接（48 通道）；
3. 3×3 卷积 → 24 通道，ReLU；
4. 1×1 线性卷积 → 4 通道；
5. Pixel-shuffle → H × W 单通道灰度。

输出只用于计算辅助损失，不送入检测头或描述子头；辅助损失通过 S1、S2 更新共享骨干；部署时整体删除。

### 4.5 学生不接收噪声条件

学生不接收 ratio、ISO、噪声水平或噪声参数图。理由：运行时的噪声条件不像合成数据那样有确定的 ratio 定义，训练时若依赖它，部署时无法提供。训练假设曝光归一化近似正确；运行时的归一化误差由使用者的方法负责，不纳入学生训练设计。

## 5. 监督与损失

### 5.1 检测蒸馏（v2：因式分解 KL）

教师为冻结的官方 MagicLeap SuperPoint，读取对应视角增强、几何变换后的 sRGB 灰度；教师在最终视角上运行，不 warp 其 65 通道输出。学生随机初始化。

对每个 cell，记 d = P(无关键点)，m = 1−d，q = P(位置 | 有关键点)（64 维条件分布）。65 类 KL 精确分解为：

$$D_{\mathrm{KL}}(P_T\parallel P_S)=\underbrace{D_{\mathrm{KL}}^{\mathrm{Bern}}(d_T\parallel d_S)}_{\text{有没有关键点}}+m_T\;\underbrace{D_{\mathrm{KL}}(q_T\parallel q_S)}_{\text{在 cell 内哪个位置}}$$

**问题**：关键点 cell 只占百分之几。按 cell 平均时，第二项被乘以 $m_T$（背景 cell 的 $m_T\approx0$），相当于被稀释约 $1/\overline{m_T}$ 倍（用合成数据验证：关键点 cell 占 2% 时约 55 倍）。网络先学会第一项，位置项学不动，表现为"无关键点概率已接近教师，关键点 cell 内响应被摊平到 64 个位置，峰值低，被检测阈值剔除"。

**v2 损失**（实现：`rawsp/losses.py::det_loss_factorized`）：位置项按教师关键点质量归一化，而不是按 cell 数：

$$L_{\mathrm{det}}=\underset{\text{views}}{\mathrm{mean}}\left[\frac{\sum_c v_c\,\mathrm{Bern}_c}{\sum_c v_c}\right]+\lambda_{\mathrm{cond}}\;\underset{\text{views}}{\mathrm{mean}}\left[\frac{\sum_c v_c\,m_{T,c}\,\mathrm{Cond}_c}{\max\!\left(\sum_c v_c\,m_{T,c},\;1\right)}\right]$$

$v_c$ 为有效 cell 掩码；$\lambda_{\mathrm{cond}}=1$ 起步（位置项仍慢时再试 2–4）；分母下限 1 防止关键点极少的视角被过度放大。两项都是严格的 KL，教师匹配的含义不变。

### 5.2 描述子匹配

| 项目 | 经验配置 |
|---|---:|
| 每对图像的对应点数量上限 | 512 |
| 教师关键点 / 空间均匀采样比例 | 75% / 25% |
| 最小点间距 | 两个视角中均为 8 个原图像素 |
| softmax 温度 τ | 0.1 |
| 负样本 | 当前图像对内的其他采样位置 |

教师点从两个视角均衡选取，用 homography 生成精确对应位置；教师点不足时用有效区域内均匀采样补充，不复制点凑数；过滤重复或过近位置；在描述子图上**插值取值，不取整到 1/8 网格**。对归一化描述子对 $(a_i,b_i)$：

$$S_{ij}=a_i^\top b_j/\tau,\quad P_{ij}=\mathrm{softmax}_j(S_{ij})\,\mathrm{softmax}_i(S_{ij}),\quad L_{\mathrm{match}}=-\frac1{2N}\sum_{i=1}^N\log P_{ii}$$

借鉴 LoFTR 的双向匹配概率监督，两个方向等权，不引入 LoFTR 网络。参考实现：`rawsp/losses.py::dual_softmax_loss`、`rawsp/geometry.py::sample_descriptors`。

### 5.3 辅助灰度损失

基于 clean 目标亮度的加权 MSE：

$$w_p=\frac1{(Y_p+\epsilon)^2},\ \epsilon=0.01,\qquad L_{\mathrm{gray}}=\frac{\sum_p m_pw_p(\hat Y_p-Y_p)^2}{\sum_p m_pw_p}$$

$m_p$ 为有效区域掩码。借鉴 RawNeRF 暗部加权思路；权重来自 clean 目标，而非 RawNeRF 里停止梯度的预测值。**ε 的取值依赖 clean 目标的实际尺度，须用 `gray_weight_report` 在实测 Y 分布上校准；若权重被最暗像素主导，按 §15.2 排查。**

### 5.4 平均方式与总损失

检测：每个视角按 §5.1 计算后平均两个视角；匹配：每对图按有效对应点平均，两个方向等权；灰度：每个视角按有效权重之和加权平均，再平均两个视角；最后对 batch 内图像对等权平均。

$$L=L_{\mathrm{det}}+L_{\mathrm{match}}+\lambda_{\mathrm{gray}}(t)\,L_{\mathrm{gray}}$$

经验权重：检测 1.0、匹配 1.0、灰度前期 10.0、后期 1.0。不使用 clean/noisy 描述子一致性，不引入自动损失平衡。

## 6. 优化器与训练基础配置

单 GPU 为基准；step 指一次优化器更新。

| 项目 | 经验值 |
|---|---|
| 每次前向 batch | 4 对（8 个视角） |
| 梯度累积 | 4（1 表示关闭） → 有效 batch 16 对 |
| 总更新次数 | 100,000（≈ COCO train2017 的 13.5 个 epoch，仅辅助记录） |
| 优化器 | AdamW，betas (0.9, 0.999)，eps 1e-8，权重衰减 1e-4 |
| 学习率 | 峰值 3e-4，初始 3e-6，最低 3e-6 |
| 精度 | FP32 |
| BN | eps 1e-5，momentum 0.1 |
| 梯度范数裁剪 | 临时阈值 5.0，试训后校准 |
| 随机种子 | 42 |

- 初始化：带 ReLU 的卷积 Kaiming；三个头的最终线性输出卷积 Xavier（gain=0.1，bias=0）；BN 缩放 1、偏移 0。
- 参数分组：卷积权重衰减；BN 参数和 bias 不衰减；学生各模块相同基础学习率；教师和 InvISP 冻结。
- 每次前向把当前 batch 的两个视角拼接通过学生，BN 用这次实际前向的 batch 统计；梯度累积不扩大 BN 统计 batch。每次小批量损失除以累积次数，累计完成后裁剪、更新一次。显存不足时优先"每次 2 对、累积 8 次"，并记录实际 BN batch 的变化。
- 不加参数滑动平均，不做训练后 BN 重估。

## 7. 训练调度

### 7.1 学习率

0–2,000 步从 3e-6 线性预热到 3e-4；2,000–100,000 步单次余弦衰减到 3e-6；不重启，不在阶段间重置优化器。

$$q=\frac{t-2000}{98000},\qquad \eta(t)=\eta_{\min}+\frac{\eta_{\max}-\eta_{\min}}2\,(1+\cos\pi q)$$

### 7.2 ratio 上限

| 参数 | 值 |
|---|---:|
| initial_max_ratio / max_ratio | 1 / 256 |
| start_step / ramp_steps | 5,000 / 35,000（第 40,000 步达到最终上限） |

$$u=\mathrm{clip}\!\left(\tfrac{t-5000}{35000},0,1\right),\quad s=\tfrac{1-\cos\pi u}{2},\quad R(t)=e^{s\ln256},\quad r=e^{v\ln R(t)},\ v\sim U(0,1)$$

两个视角共享当前上限 R(t)，各自独立采样 r 和噪声（对数均匀）；增长完成后继续在 [1,256] 内采样，保留轻噪声样本。**ratio=1 仍加 ELD 噪声**，只有显式不加噪的数据才是 clean。256 是经验上限，实施时结合实际曝光范围确认。

### 7.3 灰度辅助权重

0–60,000 步保持 10.0；60,000–80,000 步余弦下降到 1.0；80,000–100,000 步保持 1.0。

### 7.4 联合时间线

| 步数 | 学习安排 |
|---|---|
| 0–2k | 学习率预热，保持初始噪声范围 |
| 2k–5k | 建立基础检测与匹配能力 |
| 5k–40k | 平滑扩展噪声范围 |
| 40k–60k | 完整噪声分布下适应 |
| 60k–80k | 平滑降低灰度辅助影响 |
| 80k–100k | 固定最终数据分布和损失权重，低学习率收敛 |

三个损失从训练开始就启用。

## 8. 单次更新与稳定性

1. 读取全局步数，确定本步 ratio 上限和损失权重；优化器持有本步学习率。
2. 清空梯度。
3. 生成小批量的两个视角、教师目标、辅助灰度目标和有效掩码。
4. 教师和 InvISP 在无梯度条件下运行。
5. 拼接两个视角执行学生前向，构造几何对应，计算三项损失。
6. 损失按累积次数缩放，反向传播；重复到累积完成。
7. 记录裁剪前梯度范数，检查有限性，执行一次全局范数裁剪。
8. 执行一次优化器更新。
9. 推进全局步数和学习率调度。
10. 到间隔时记录日志、验证、保存。

小型试训中偶尔检查三项损失对共享骨干的梯度，确认检测与匹配有有效信号、灰度任务没有明显压过主体任务、描述子没有退化成近似相同的向量。这些观测用于人工校准固定配置，不构成运行时自动权重算法。出现非有限损失或梯度时记录样本和训练状态并定位原因，不静默替换异常值继续训练。

## 9. 验证与评估

### 9.1 阶段 1：固定 COCO 验证

- 从 COCO val2017 固定选 256 张源图像，各建一组固定基础图像对；验证种子 2027，与训练随机流分开；固定图像编号、裁剪、homography、两视角增强及噪声参数；可预生成或缓存，不要求每次重跑 InvISP；验证范围从训练早期起保持一致。
- ratio 档位 [1, 4, 16, 64, 256]，每档 256 对：一半两视角均用该档位，一半一边 ratio=1、另一边为该档位（方向均衡）。共 1,280 对含噪 + 256 对完全不加 ELD 噪声的 clean，总计约 1,536 对。验证规模与间隔按小试耗时校准，正式选模型前固定协议。

### 9.2 提取与匹配

| 项目 | 值 |
|---|---:|
| NMS 半径 | 4 个原图像素 |
| 检测阈值 | 0.005 |
| 每张最大关键点数 | 1,024 |
| 边界过滤 | 8 个原图像素 |
| 匹配 | 互为最近邻，不用 ratio test |

Homography 用成熟库 RANSAC：重投影阈值 3 像素，置信度 0.999，最大迭代 10,000，随机种子固定；几何估计失败记为失败，不移除样本。

**v2 增加一组阈值无关的评估**：同一批数据另报"仅 Top-K（阈值取 0）"的全部指标，学生与基线同时运行。这样可把"得分校准"（阈值剔除）与"定位排序质量"（热图本身的好坏）分开，直接服务于 §15.1 的诊断。

### 9.3 指标与选模型

由匹配估计 homography，与真值 homography 映射图像四角的结果比较，得到平均角点误差（像素单位为固定验证尺寸下未打包 Bayer 的尺度）。

主分数为五档等权平均的 H-AUC@5px：

$$\mathrm{Score}=\tfrac15\sum_{k=1}^{5}\text{H-AUC@5px}_k$$

clean 组单独报告，不入主分数。同时报告：各档 H-AUC@1/3/5px；关键点重复性（距离阈值待定，见 §17）、定位误差；匹配精度、正确匹配数；实际检测点数与匹配点数；§15.1 的 `det_diagnostics` 全部字段。总训练损失不作为选模型依据；阶段 1 只用固定 COCO 验证集。

### 9.4 阶段 2（阶段 1 良好后）

- **合成 HPatches-raw**：用同一套合成流程生成 HPatches 的含噪 Raw 版本，固定噪声种子，按 ratio 分桶；homography 真值直接可用。
- **MID**：真实低光 Raw 配对数据，带真值相对位姿；只推理，不参与训练。你自己的 K60/Blackfly 少量真实帧可作为 MID 到位前的定性检查（可视化，不参与选模型）。

## 10. MeanAD + SuperPoint 对照基线

### 10.1 定位

基线就是你实际使用、表现较好的"raw + 归一化 + SuperPoint"。MeanAD 是真实 Raw 运行时未知曝光条件下的兼容处理，仅用于基线；不用于学生输入、教师输入、辅助灰度目标或任何训练损失。参考仓库 rongjie-yu/Raw-SLAM，核对版本 master 提交 `9a6645b0`；**以下基线细节我未能在线核实源码，需你用本地代码做单元测试核对（§12.3）。**

### 10.2 可比性说明

学生训练与验证使用已知的真值 ratio 做曝光归一化，基线用 MeanAD 盲归一化，因此"学生 − 基线"的差值包含归一化方式的差异。这是有意的（基线即实际流程，目标是超过它）。若之后需要把网络与归一化各自的贡献拆开，可选做"SuperPoint + 真值曝光归一化"；若需量化部署差距，可把验证集含噪 Bayer 经你实际部署的归一化后只推理喂给学生。两者都非必须。

### 10.3 实际顺序

```text
含噪 Bayer → 双线性 demosaic 与电平处理 → 三通道 Linear Raw
  → 三通道联合 MeanAD（逐通道裁剪）→ RGB 转灰度 → 原版 SuperPoint → 互为最近邻
```

保留"MeanAD 在灰度转换之前"的顺序。

### 10.4 COCO 基线复用的合成 Raw 路径

1. `colour_demosaicing.demosaicing_CFA_Bayer_bilinear`，RGGB；
2. 减黑电平 2048；
3. 裁剪到 [0, 16383−2048]；
4. 除以 16383（代码分母不是 16383−2048，故归一化上界约 0.875）；
5. 编码为 uint16 Linear Raw，运行时除以 65535 恢复浮点；
6. 此路径不额外应用白平衡。

保留 uint16 量化语义，可在内存中完成；电平转换按输入所处数值域衔接，不能对已减黑、已归一化的数据再减 2048。

### 10.5 MeanAD 精确定义

对当前三通道输入的全部 H×W×3 个数值计算一个共享均值和平均绝对偏差：

$$m=\tfrac1N\sum_i x_i,\quad d=\tfrac1N\sum_i|x_i-m|,\quad z_i=\mathrm{clip}\!\left(\tfrac{x_i-m+2d}{4d+\epsilon},0,1\right),\ \epsilon=10^{-8}$$

不按通道分别统计；用完整输入图像，不忽略零值，不传有效区域掩码；统计量用 double 累加，输出 float32；d ≤ ε 时输出全零；之后用 OpenCV COLOR_RGB2GRAY；SuperPoint 直接接收 [0,1] 的 float32 单通道，不再除 255。验证损失和几何评价的有效掩码规则，与 MeanAD 自身的整帧统计规则分别保留。

### 10.6 真实 Raw 入口（记录旧项目实现，本阶段不新增真实数据评估）

| 入口 | 当前实现 |
|---|---|
| K60 | rawpy LINEAR demosaic；Raw 色彩空间；16 位；gamma=(1,1)；关闭自动亮度、自动缩放和白平衡；传入元数据黑白电平，按白电平归一化并编码 |
| Blackfly | OpenCV 双线性 demosaic；0–65520 映射到 uint16 的 0–65535；不加白平衡、Gamma、曝光补偿、颜色矩阵 |

不同入口不共用物理黑白电平，进入特征提取后调用相同的 MeanAD 函数。

### 10.7 基线测量与比较

学生和基线从同一份含噪 Bayer 分流，各自执行已确定的预处理；用同一 COCO 验证清单、同一噪声实现、同一几何关系和有效区域；统一的特征数量预算、互为最近邻、几何估计规则。验证集与基线配置固定后运行一次基线，保存逐图预测和全部分桶指标；之后每个学生检查点报告学生指标、基线指标和差值（AUC 等百分比指标以百分点差为主）；若修改验证清单或基线预处理，重新运行基线。基线的裁剪、白平衡和 MeanAD 不移植到学生训练；当前对比不含 LightGlue 或 SLAM。

## 14. 在线数据生成的效率

在线 InvISP 的成本无法回避（100k 次更新 × 16 对 × 2 视角 ≈ 320 万次 InvISP 前向，另有同量级教师前向），因此要尽量提高效率。**先测量再优化：先在 §12.1 的短检查里分段计时，只优化占比最大的段。**

| 措施 | 说明 |
|---|---|
| 批量化 | 两个视角、整个小批量（8 个视角）合并为一次 InvISP 调用和一次教师调用 |
| 推理模式 | InvISP 和教师在 `torch.inference_mode()` 下运行；`channels_last`；`cudnn.benchmark` |
| 数据准备与计算重叠 | DataLoader worker 做 CPU 端增强（Albumentations 在 uint8 图像上），多 worker、`persistent_workers`、pin memory；用独立 CUDA stream 预取下一个小批量，与当前反向传播重叠 |
| ELD 上 GPU | ELD 参考实现是 numpy；散粒噪声可用 `torch.poisson`，Tukey-lambda 读出噪声可用逆变换采样，行噪声和量化噪声也是简单张量运算。移植后须与 CPU 实现对比分布（矩与分位数）；仅当 CPU 端成为瓶颈时才做 |
| 低精度推理 | InvISP/教师在 FP16 下运行可能更快。须先验证：同一批输入下 FP16 与 FP32 输出的差异远小于 8-bit 源图的量化步长；不通过则保持 FP32 |
| 避免无效计算 | 在 480×640 基础裁剪上运行 InvISP（而非整张 COCO）；warp 只对有效区域所需像素做 |

## 15. 已知问题与排查手册

### 15.1 检测头响应被摊平（短训观察到）

**现象**：关键点 cell 内的 64 个位置概率被摊平，热图峰值很低，被检测阈值剔除；而"无关键点"概率已接近教师。

**为什么会这样（三个可叠加的原因）**：
- **位置项被稀释**：见 §5.1，约 1/(教师关键点质量均值) 倍。前向 KL 又是"覆盖式"的：位置不确定时，最优解就是摊平的边缘分布，所以"没学会位置"在外观上就是摊平。这是首要嫌疑，且已有修复。
- **结构缺少亚 cell 定位信息**：S3 在 1/8 分辨率，65 类要求在 8×8 内精确定位；骨干是逐级 stride-2，没有跳连时高分辨率细节可能在下采样中丢失。
- **教师与学生网格错位**：只要有系统性亚像素偏移，最优预测就会变成摊平分布。

**诊断（全部不需要正式训练）**，每次验证记录 `det_diagnostics` 并按下表读：

| 步骤 | 做法 |
|---|---|
| 1 | 记录 `det_diagnostics`，看 bern_kl、cond_kl_w、两个条件熵（ln64≈4.16 为完全摊平）、峰值、top1_agree、top1_dist_px、frac_peak_above_thr |
| 2 | **clean 对照**：同一模型在无噪声输入上是否也摊平 |
| 3 | **小集过拟合**：32 对、无噪声、固定增强，训几百到几千步，能否复现教师的尖峰 |
| 4 | **对齐检查**：§12.3 的教师/学生对齐测试 |
| 5 | **BN 模式对照**：同一批验证数据，eval 模式 vs train 模式（batch 统计）的峰值差异 |

| 观察 | 最可能原因 | 修复 |
|---|---|---|
| bern_kl 低、cond_kl_w 高；clean 也摊平；小集过拟合可复现教师 | 位置项被稀释 | 使用 `det_loss_factorized`（已实现）；位置项仍慢则 λ_cond 取 2–4 |
| clean 摊平，且小集过拟合也失败 | 结构缺少亚 cell 定位信息 | ①打开 `use_skip`；②仍不足：用 space-to-depth 无损下采样替代 stride-2；③再不足：增加像素级 logit 分支，经 space-to-depth 重排成 64 个位置通道，并与 1/8 头的 dustbin 通道拼成 65 类（保持输出格式和蒸馏方式） |
| top1_dist_px 呈系统性偏移，或对齐检查位移 ≥ 0.5 像素 | 网格错位 | 修对齐（Bayer 打包偏移、warp 约定、灰度目标），不要靠损失掩盖 |
| clean 尖锐，仅高 ratio 才摊平 | 噪声造成的真实不确定性（部分合理） | 看是否随课程恢复；比较 §15.3 |
| KL 与峰值都正常但检测点少 | 得分校准 | 用 Top-K 评估；必要时按学生分数分布标定阈值（不改损失） |

**可选辅助**：位置项慢时，训练早期加一个对教师 argmax 的硬标签交叉熵（权重 0.1–0.3，仅在关键点 cell），使分布更尖；位置项收敛本来就慢于"有无"项，先看完整的曲线再判断是否欠训练。

### 15.2 辅助灰度权重可能被最暗像素主导

**原理**：权重 $1/(Y+0.01)^2$ 在 Y≈0 时约 1e4，Y≈0.2 时约 23，动态范围 400 倍以上。又因按 Σw 归一化，若 clean 目标有大量接近纯黑的像素（sRGB 纯黑，加上 8-bit 量化台阶），这些噪声最强、最不可恢复的像素会占去大部分损失，辅助头把能量花在不可恢复的区域。

**现象**：辅助损失下降但降噪视觉效果差（暗部噪声拟合、亮部和中间调模糊）；辅助损失的梯度范数占比异常大；λ_gray 提高时检测、匹配指标变差；`gray_weight_report` 里少量最暗像素占大部分权重质量。

**排查**：对一批 clean 目标运行 `rawsp.losses.gray_weight_report(Y, valid, eps)`，读：
- `Y_p1…Y_p95`：Y 的真实分位数（先确认"白值约 1"的假设；基线路径的上界约 0.875）；
- `pix_frac_y<t` 与 `weight_frac_y<t`：最暗像素的占比与权重占比；
- `effective_pixel_frac`（Kish 有效样本比例）。

**判据（经验值，需校准）**：Y<0.01 的像素权重质量占比 > 50%，或有效像素比例 < 0.1，视为被主导。

**修复（侵入性从低到高，逐级尝试，每级后重跑 `gray_weight_report`）**：
1. 提高 ε（0.01 → 0.03 → 0.05）；
2. 权重封顶：w = min(w, w_max)；
3. 噪声底下限：用 max(Y, c·σ_noise(r)) 代替 Y 计算权重（σ_noise 为该 ratio 下 ELD 的期望噪声标准差，c≈1），使低于噪声底的像素权重不再增长；
4. 掩码：把 clean 目标低于 8-bit 量化台阶对应线性值（约 1/255 的线性值）的像素 m_p 置 0；
5. 混合：L = (1−β)·L_w + β·L_plain，β = 0.1–0.3；
6. 降低 λ_gray 前期权重（10 → 3）。

### 15.3 BN 与异质噪声水平

学生不知道噪声水平，BN 的 running 统计量是整个 ratio 分布的平均，部署时融合进卷积的也是这组统计量；若按单一 ratio 档位评估，可能不匹配。**诊断**：同一批验证数据，分档比较 eval 模式（running 统计量）与 train 模式（batch 统计量）的指标；差距大（经验：H-AUC 差 > 2 个百分点）才处理。候选处理（按侵入性）：用目标 ratio 分布重估 BN（与"不做训练后 BN 重估"的现行规定冲突，须你决定）；换 GroupNorm 对比。噪声条件已因运行时无确定 ratio 而不采用（§4.5）。

### 15.4 其他备注（不立即处理）

- 视角 A 恒为未 warp、B 恒为 warp，B 因双线性插值更平滑，学生可能利用；SuperPoint 原版同样如此，风险低。若想消除，可对 A 也施加小的随机变换。
- 五档 H-AUC 可能出现低 ratio 档饱和、高 ratio 档接近 0，使主分数区分度不足；小试时先看各档位分布。
- 模糊在 sRGB 阶段施加、早于 warp，而真实运动模糊发生在线性域；旋转后核方向会变，影响不大。
- ratio 上限 256 与 InvISP clean 暗部的 8-bit 量化、ELD 标定范围的关系，需与真实曝光范围对照。
- 学生训练中从未见过无噪声输入（ratio=1 也加噪）；clean 组验证用于检查这一点的影响。
- 选模型只依据合成验证分数，阶段 2 之前没有真实数据检验（sim-to-real 风险：InvISP 来自 8-bit JPEG，COCO 图像的 ISP 风格不统一）。
