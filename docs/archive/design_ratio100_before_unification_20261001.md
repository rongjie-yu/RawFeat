# 低光 Raw 特征点与描述子提取器设计

- 日期：2026-09-29
- 状态：已有实现、固定 COCO 基线和有限试训；正式训练未启动，灰度权重仍待实测标定。
- 本文范围：整理本次讨论已经确认的方案，不增加新的模型、损失或评估任务。
- 数值性质：网络结构与方法路线已确定；训练配置中的经验值将在实施时通过小型试训校准。
- 2026-09-30 用户校正：正式训练 max ratio=100，主验证档位为 [1,4,16,64,100]；旧256档只保留历史压力结果。灰度权重10仍是待实测标定的经验起点，不代表已经验证为合适。

## 1. 目标与范围

训练一个直接接收 Bayer Raw 的单一整体网络，在低光噪声下提取稳定的关键点和描述子，最终服务于在线 SLAM。

本阶段只完成提取器、训练流程和固定 COCO 验证：

1. 输出原始 Bayer 坐标系下的关键点位置、检测分数和 128 维描述子。
2. 优化关键点重复性、定位准确性、描述子的匹配精度及正确匹配数量。
3. 与 Raw-SLAM 中已经实际使用的 MeanAD + SuperPoint 预处理基线进行对比。
4. 报告参数量、MACs 和实测延迟，作为比较指标，不设置硬性延迟目标。

本阶段不开展 HPatches-raw、MID、真实 SLAM 集成评估；不加入 LightGlue、词典、回环、二值描述子、INT8 或 FP16 优化。

降噪能力由共享网络学习，不采用独立降噪器与提取器级联。训练期的辅助灰度头只提供降噪引导，部署时删除。

## 2. 总体流程

### 2.1 训练

```text
COCO sRGB
  → 保持宽高比缩放、尺度变化、裁剪
  → 两个视角独立抽取一种 sRGB 外观操作
  → 每个视角在线执行冻结的 InvISP，得到 clean 三通道线性 Raw
  → 同一视角的 sRGB 与 clean Raw 应用相同几何变换
      ├─ sRGB 灰度 → 冻结的 SuperPoint 教师 → 检测软目标
      └─ clean Raw
          ├─ 线性灰度 → 辅助灰度目标
          └─ Bayer 采样 → ELD 噪声与曝光归一化 → 四通道打包
                → 学生共享骨干
                    ├─ 检测头
                    ├─ 描述子头
                    └─ 辅助灰度头（仅训练）
```

训练损失只有三项：检测蒸馏、几何匹配、辅助灰度重建。已删除 clean/noisy 描述子一致性，不运行额外的 clean 描述子分支。

### 2.2 部署

```text
Raw 线性预处理
  → [R, G1, G2, B] 打包
  → 已融合的 RepVGG 骨干
  → 检测头和描述子头
  → 关键点筛选、描述子采样、裁剪坐标恢复
```

学生不接收 ratio、ISO、噪声水平或噪声参数图。训练假设曝光归一化近似正确；运行时未知曝光条件下的兼容处理由用户负责，不纳入学生训练设计。

## 3. 数据与预处理

### 3.1 数据来源与图像尺寸

| 项目 | 配置 |
|---|---|
| 训练集 | COCO train2017 |
| 训练期间验证集 | COCO val2017 的固定子集，与训练源图像不重合 |
| 原始 Bayer 尺寸 | 高 480、宽 640 |
| 学生输入尺寸 | 4 × 240 × 320 |
| 基础缩放 | 保持宽高比，缩放到能够覆盖目标裁剪区域 |
| 额外尺度变化 | 基础缩放倍率的 1.0–1.2 倍 |
| 训练裁剪 | 随机裁剪 |
| 验证裁剪 | 固定裁剪 |

基础缩放和裁剪在 sRGB 阶段完成，避免将图像直接拉伸到目标宽高比。尺寸为 8 的倍数。

### 3.2 sRGB 随机外观增强

两个视角的操作类别和参数独立采样。每个视角最多执行一种外观增强。

| 操作 | 每个视角的概率 | 参数 |
|---|---:|---|
| 保持原始外观 | 70% | NoOp |
| 亮度 | 5% | 因子 0.9–1.1 |
| 对比度 | 5% | 因子 0.85–1.15 |
| Gamma | 5% | 指数 0.85–1.15 |
| 饱和度 | 5% | 因子 0.8–1.2 |
| 平滑阴影 | 5% | PlasmaShadow；强度 0.1–0.35；roughness 0.7 |
| 模糊 | 5% | 高斯和运动模糊各占一半 |

等价的抽样池为“原始 × 14，其余六类各 × 1”。实现使用权重，不需要建立 14 个重复算子。

增强统一采用 Albumentations，按已核对的 2.0.8 接口实现并锁定版本与依赖。使用 OneOf 和 NoOp 实现抽样。亮度、对比度、饱和度分别配置，仅启用对应的一项；不手写增强算法。

模糊配置：

- GaussianBlur：sigma 为 0.3–1.0，核尺寸由库确定。
- MotionBlur：核尺寸 3 或 5，角度 0–180°，direction_range=(0,0)，allow_shifted=False。
- 像素尺度定义在进入 InvISP 的 sRGB 图像上。

阴影选择平滑明暗变化，减少硬边合成形状制造角点的影响。模糊使用对称、居中的核，避免引入额外方向性偏移。

不增加 sRGB 噪声、CutMix、随机擦除、通道交换、反相或额外 JPEG 压缩。传感器噪声由 Raw 域 ELD 负责。

“保持原始外观”只表示不增加 sRGB 外观变化，仍执行几何变换和 Raw 噪声合成。两个视角独立抽样时，49% 的图像对两边保持原样，42% 仅一边增强，9% 两边增强。

### 3.3 在线 InvISP

每个视角的 sRGB 增强结果分别输入 InvISP，生成对应的 clean 三通道线性 Raw。

- InvISP 冻结，在评估模式下执行，不参与反向传播。
- 训练时在线运行，不缓存固定的 InvISP 输出替代随机增强。
- 教师输入和 clean Raw 必须来自同一份增强结果。
- 教师的“干净输入”表示没有模拟传感器噪声，允许存在本节确定的外观增强。

### 3.4 几何变换与有效区域

| 项目 | 经验配置 |
|---|---|
| 参考视角 A | 基础裁剪坐标系 |
| 目标视角 B | 随机仿射变换，再叠加轻度透视变换 |
| 旋转 | −30°～30° |
| 缩放 | 0.8–1.2 |
| 水平、垂直平移 | 分别不超过图像尺寸的 10% |
| 透视扰动 | Kornia distortion_scale=0.15 的轻度设置 |
| 共同有效区域 | 至少覆盖两个视角各自面积的 50%，不足时重新采样 |

使用成熟库生成、执行变换，并保存准确的变换矩阵。裁剪、缩放和 warp 都计入对应关系。

同一视角的 sRGB 和三通道线性 Raw 应用同一个几何变换。先对三通道 Raw 做 warp，再采样 Bayer、添加噪声，不直接 warp 马赛克或已有噪声。

有效区域掩码随几何变换传播。无效区域不参与损失；有效区域边缘收缩 8 个原图像素。检测监督仅保留整个 8×8 cell 都有效的位置。

### 3.5 曝光倍率和 ELD 噪声

沿用已经验证过的合成路线：

\[
x_{\mathrm{noisy}}
=r\left[x_{\mathrm{clean}}/r+n_{\mathrm{ELD}}(x_{\mathrm{clean}}/r)\right].
\]

ratio 越大，模拟曝光越低。两个视角独立采样 ratio，噪声也独立生成。

ELD 使用实际相机标定配置，在其对应的传感器数值域生成噪声。黑白电平、白平衡与曝光增益的处理顺序保持数值域一致，不重复减黑电平或重复应用增益。

学生输入完成既定的黑白电平、白平衡、曝光归一化后，打包为 [R,G1,G2,B]。不增加非线性压缩，不将曝光归一化后的含噪输入简单裁剪到 [0,1]，保留负值。

固定 CFA 相位；本阶段不处理随机 CFA、G1/G2 交换或绿色通道增益扰动。

### 3.6 辅助灰度目标

从原分辨率、完成相同几何变换与线性归一化的 clean 三通道 Raw 生成：

\[
Y_{\mathrm{clean}}=0.299R+0.587G+0.114B.
\]

若以两个绿色采样表达绿色，其定义是取平均：

\[
Y=0.299R+0.587(G_1+G_2)/2+0.114B.
\]

实际辅助目标使用前一个全分辨率公式，不通过 packed 四通道合成为低分辨率目标。

目标保留该视角的 sRGB 阴影、模糊及其他增强效果。辅助头提供传感器降噪引导，不要求撤销这些外观增强。

## 4. 网络

### 4.1 共享骨干

所有空间尺寸相对原始 Bayer 的 H×W 表示。

| 阶段 | 输出空间尺寸 | 通道 | 块数 | 下采样 |
|---|---|---:|---:|---|
| 输入 | H/2 × W/2 | 4 | — | Bayer 打包 |
| S1 | H/2 × W/2 | 24 | 2 | 无 |
| S2 | H/4 × W/4 | 48 | 3 | 第一个块步长 2 |
| S3 | H/8 × W/8 | 96 | 4 | 第一个块步长 2 |

S1/S2/S3 是连续三组卷积层，共同完成噪声处理和特征提取，不规定某一段只负责降噪。

采用 RepVGG：训练期每个块使用 3×3+BN、1×1+BN，以及尺寸和通道允许时的恒等+BN 分支；分支相加后接 ReLU。部署时融合为单个带偏置的 3×3 卷积和 ReLU。

不加入 H/4→H/8 跨阶段跳连、金字塔、大核、注意力、Transformer、Mamba 或噪声条件 FiLM。

### 4.2 检测头

```text
S3（96 通道）
  → 独立 RepVGG 块（128 通道）
  → 1×1 线性卷积（65 通道）
```

输出尺寸为 65×H/8×W/8。每个 cell 的 65 类对应原图 8×8 区域中的 64 个像素，以及一个“无关键点”类别。

推理时 softmax、移除“无关键点”通道、重排为原图分数图，再做边界过滤、NMS 和数量筛选。关键点坐标恢复裁剪偏移。

### 4.3 描述子头

```text
S3（96 通道）
  → 独立 RepVGG 块（128 通道）
  → 1×1 线性卷积（128 通道）
```

输出尺寸为 128×H/8×W/8。网格描述子做 L2 归一化，在关键点位置双线性插值后再次归一化。

描述子完全在学生自己的空间学习，不对齐教师描述子。

### 4.4 辅助灰度头

1. S2 通过 1×1 卷积降到 24 通道，上采样到 S1 尺寸。
2. 与 S1 拼接，得到 48 通道。
3. 3×3 卷积得到 24 通道，接 ReLU。
4. 1×1 线性卷积输出四通道。
5. Pixel-shuffle 得到 H×W 单通道灰度。

辅助输出仅计算损失，不送入检测头或描述子头。辅助损失通过 S1、S2 更新共享骨干。部署时删除整个辅助头。

## 5. 监督与损失

### 5.1 检测蒸馏

教师为冻结的官方 MagicLeap SuperPoint，读取对应视角增强、几何变换后的 sRGB 灰度。教师在最终视角上运行，不直接 warp 其 65 通道输出。

教师和学生的 65 类 softmax 概率使用教师到学生方向的 KL，温度为 1，包含“无关键点”类别：

\[
L_{\mathrm{det}}=\operatorname{mean}_{\mathrm{valid\ cells}}
D_{\mathrm{KL}}(P_T\parallel P_S).
\]

学生随机初始化，不使用教师权重初始化。

### 5.2 描述子匹配

| 项目 | 经验配置 |
|---|---:|
| 每对图像的对应点数量上限 | 512 |
| 教师关键点采样比例 | 75% |
| 空间均匀采样比例 | 25% |
| 最小点间距 | 两个视角中均为 8 个原图像素 |
| softmax 温度 | 0.1 |
| 负样本 | 当前图像对内的其他采样位置 |

教师点从两个视角均衡选取，利用 homography 生成精确对应位置。教师点不足时以有效区域内均匀采样补充；不复制点凑数量。过滤重复或过近位置，在描述子图上插值取值，不将对应位置直接取整到 1/8 网格。

设归一化描述子对为 (a_i,b_i)，构造：

\[
S_{ij}=a_i^\top b_j/\tau,
\qquad
P_{ij}=\operatorname{softmax}_j(S_{ij})
\operatorname{softmax}_i(S_{ij}).
\]

真实对应排列在对角线上，损失为：

\[
L_{\mathrm{match}}=-\frac{1}{2N}\sum_{i=1}^{N}\log P_{ii}.
\]

这是借鉴 LoFTR 的双向匹配概率监督。两个方向等权，不引入 LoFTR 网络或跨图像特征交互。

### 5.3 辅助灰度损失

采用基于 clean 目标亮度的加权 MSE：

\[
w_p=\frac{1}{(Y_p+\epsilon)^2},\qquad \epsilon=0.01,
\]

\[
L_{\mathrm{gray}}=
\frac{\sum_p m_pw_p(\hat Y_p-Y_p)^2}{\sum_p m_pw_p}.
\]

m_p 为有效区域掩码。epsilon 的数值对应 clean 目标典型白值约为 1 的约定尺度。

这是借鉴 RawNeRF 暗部加权思路、针对已有 clean 监督的修改。权重来自 clean 目标，不是原始 RawNeRF 中停止梯度的预测值。

### 5.4 平均方式与总损失

- 检测：每个视角按有效 cell 平均，再平均两个视角。
- 匹配：每对图按有效对应点平均，两个方向等权。
- 灰度：每个视角按有效权重之和计算加权平均，再平均两个视角。
- 最后对 batch 内图像对等权平均，再组合三项损失。

\[
L=L_{\mathrm{det}}+L_{\mathrm{match}}
+\lambda_{\mathrm{gray}}(t)L_{\mathrm{gray}}.
\]

经验权重为检测 1.0、匹配 1.0、灰度前期暂存 10.0、后期 1.0。10是尚未确认合适的经验起点；已有稳定性与局部梯度观测不能代替权重对照实验。灰度系数是小型试训中优先校准的参数。

不使用 clean/noisy 描述子一致性，不运行 clean 描述子参考分支，不引入自动损失平衡算法。

## 6. 优化器与训练基础配置

以下以单 GPU 为配置基准，step 指一次优化器更新，epoch 仅作辅助记录。

| 项目 | 经验值 |
|---|---|
| 每次前向 batch | 4 对图像，即 8 个视角 |
| 梯度累积次数 | 4 |
| 有效 batch | 16 对图像 |
| 总更新次数 | 100,000 |
| 优化器 | AdamW |
| 峰值学习率 | 3e-4 |
| 初始学习率 | 3e-6 |
| 最低学习率 | 3e-6 |
| AdamW betas | (0.9, 0.999) |
| AdamW epsilon | 1e-8 |
| 权重衰减 | 1e-4 |
| 计算精度 | FP32 |
| BN epsilon | 1e-5 |
| BN momentum | 0.1 |
| 全局梯度范数裁剪 | 临时阈值 5.0，试训后按实际梯度校准 |
| 训练随机种子 | 42 |

初始化和参数分组：

- 带 ReLU 的卷积使用 Kaiming 初始化。
- 三个头的最终线性输出卷积使用 Xavier 初始化，gain=0.1，bias=0。
- BN 缩放初始化为 1、偏移为 0。
- 卷积权重使用权重衰减；BN 参数和 bias 不衰减。
- 学生各模块采用相同基础学习率。
- 教师和 InvISP 冻结，不进入学生优化器。

每次前向将当前 batch 的两个视角拼接后共同通过学生。BN 根据这次实际前向的 batch 计算统计；梯度累积不扩大 BN 的统计 batch。

梯度累积次数作为配置项，1 表示关闭。每次小批量损失除以累积次数，累计完成后裁剪、更新一次。若显存不足，优先尝试每次 2 对、累积 8 次以维持有效 batch=16，并记录实际 BN batch 的变化。

不增加参数滑动平均或训练后的 BN 重估。

## 7. 三条训练调度

### 7.1 学习率

- 0–2,000 步：从 3e-6 线性预热到 3e-4。
- 2,000–100,000 步：单次余弦衰减到 3e-6。
- 预热包含在总训练步数内。
- 不重启学习率，不在课程阶段之间重置优化器。

预热后的学习率为：

\[
q=\frac{t-2000}{100000-2000},\qquad
\eta(t)=\eta_{\min}
+\frac{\eta_{\max}-\eta_{\min}}2(1+\cos(\pi q)).
\]

### 7.2 ratio 上限

| 参数 | 经验值 |
|---|---:|
| initial_max_ratio | 1 |
| max_ratio | 100 |
| start_step | 5,000 |
| ramp_steps | 35,000 |
| 达到最终上限 | 第 40,000 步 |
| 区间内采样 | 对数均匀 |

\[
u=\operatorname{clip}\left(\frac{t-5000}{35000},0,1\right),\qquad
s=\frac{1-\cos(\pi u)}2,
\]

\[
R(t)=\exp(s\ln100),\qquad
r=\exp(v\ln R(t)),\quad v\sim U(0,1).
\]

两个视角共享当前上限 R(t)，各自独立采样 r 和噪声。增长完成后继续在 [1,100] 内采样，保留轻噪声样本。

ratio=1 仍会添加 ELD 噪声；只有显式不加噪的数据才是 clean。

100 是用户当前确定的正式训练上限；旧256上限不再作为训练要求。

### 7.3 灰度辅助权重

- 0–60,000 步：保持 10.0。
- 60,000–80,000 步：余弦下降到 1.0。
- 80,000–100,000 步：保持 1.0。

### 7.4 联合时间线

| 更新步数 | 学习安排 |
|---|---|
| 0–2k | 学习率预热，保持初始噪声范围 |
| 2k–5k | 建立基础检测与匹配能力 |
| 5k–40k | 平滑扩展噪声范围 |
| 40k–60k | 在完整噪声分布下适应 |
| 60k–80k | 平滑降低灰度辅助影响 |
| 80k–100k | 固定最终数据分布和损失权重，低学习率收敛 |

三个损失从训练开始就启用。最终噪声范围在学习率尚有足够更新幅度时出现，避免接近训练结束才引入最难样本。

## 8. 单次更新与稳定性

一次优化器更新的顺序：

1. 读取当前全局步数，确定本步 ratio 上限和损失权重；优化器持有本步学习率。
2. 清空梯度。
3. 生成小批量的两个视角、教师目标、辅助灰度目标和有效掩码。
4. 教师和 InvISP 在无梯度条件下运行。
5. 拼接两个视角执行学生前向，构造几何对应，计算三项损失。
6. 损失按梯度累积次数缩放，反向传播；重复直到本次累积完成。
7. 记录裁剪前梯度范数，检查有限性，执行一次全局范数裁剪。
8. 执行一次优化器更新。
9. 推进全局步数和学习率调度，为下一步准备参数。
10. 到达指定间隔时记录日志、验证和保存。

小型试训中偶尔检查三项损失对共享骨干的梯度，确认检测与匹配有有效信号、灰度任务没有明显压过主体任务、描述子没有退化成近似相同的向量。

这些观测用于人工校准固定配置，不构成运行时自动权重算法。出现非有限损失或梯度时记录样本和训练状态并定位原因，不静默替换异常值长期继续训练。

## 9. 固定 COCO 验证

### 9.1 数据清单

- 从 COCO val2017 固定选择 256 张源图像，每张建立一组固定基础图像对。
- 验证随机种子为 2027，与训练随机流分开。
- 固定图像编号、裁剪、homography、两视角增强及噪声参数。
- 固定验证数据可以预生成或缓存，不要求每次验证重新运行 InvISP。
- 验证范围从训练早期起保持一致，不随训练课程变化。

ratio 档位为 [1,4,16,64,100]。每档 256 对：

- 一半图像对的两个视角均使用当前档位。
- 一半图像对的一边使用 ratio=1，另一边使用当前档位，方向均衡。

共 1,280 对含噪图像，另加 256 对完全不加 ELD 噪声的 clean 图像，总计约 1,536 对。

验证规模与间隔根据小试耗时校准，正式用于选择模型前固定协议。

### 9.2 提取与匹配

| 项目 | 经验值 |
|---|---:|
| NMS 半径 | 4 个原图像素 |
| 检测阈值 | 0.005 |
| 每张最大关键点数 | 1,024 |
| 边界过滤 | 8 个原图像素 |
| 匹配 | 互为最近邻 |
| 额外 ratio test | 不使用 |

Homography 使用成熟库的 RANSAC：重投影阈值 3 像素，置信度 0.999，最大迭代 10,000 次，随机设置固定。几何估计失败记为失败，不移除样本。

### 9.3 最佳模型指标

从匹配估计 homography，与真实 homography 对图像四角的映射结果比较，得到平均角点误差。

主分数为五个噪声档位等权平均的 H-AUC@5px：

\[
\mathrm{Score}=\frac15\sum_{k=1}^{5}\mathrm{H\text{-}AUC@5px}_k.
\]

像素单位采用固定验证尺寸下未打包 Bayer 的尺度。clean 组单独报告，不加入主分数。

同时报告：

- 各档位 H-AUC@1/3/5px；
- 关键点重复性、定位误差；
- 匹配精度、正确匹配数量；
- 实际检测点数和匹配点数。

总训练损失不作为选模型依据。当前只使用固定 COCO 验证集，不开展 HPatches-raw 或 MID 评估。

## 10. MeanAD + SuperPoint 对照基线

### 10.1 定位与边界

MeanAD 是用户真实 Raw 运行时未知曝光条件下的兼容处理，仅用于本阶段的 SuperPoint 对照基线。

MeanAD 不用于学生输入、教师输入、辅助灰度目标或任何训练损失，也不改变学生已经确定的归一化路线。

基线参考仓库：[rongjie-yu/Raw-SLAM](https://github.com/rongjie-yu/Raw-SLAM)。源码核对版本为 master 上的提交 `9a6645b0`。以下基线细节对应此版本。当前 v2 协议已运行完整 1,536 对 COCO 基线，主分数为 65.9515%；结果见 [基线记录](../outputs/baseline/summary.json)。

### 10.2 实际顺序

代码中的顺序是：

```text
含噪 Bayer
  → 双线性 demosaic 与电平处理
  → 三通道 Linear Raw
  → 三通道联合 MeanAD，并逐通道裁剪
  → RGB 转灰度
  → 原版 SuperPoint
  → 互为最近邻
```

需要保留“MeanAD 在灰度转换之前”的顺序。

### 10.3 COCO 基线复用的合成 Raw 路径

Raw-SLAM 合成路径的处理为：

1. 使用 colour_demosaicing.demosaicing_CFA_Bayer_bilinear，RGGB。
2. 减去黑电平 2048。
3. 裁剪到 [0,16383−2048]。
4. 除以 16383；代码分母不是 16383−2048。
5. 编码为 uint16 Linear Raw；运行时除以 65535 恢复浮点值。
6. 不在此路径额外应用白平衡。

实现 COCO 基线时保留 uint16 的量化语义，可在内存中完成，无需实际写 PNG。电平转换依据输入所处数值域衔接，不能对已经减黑、归一化的数据再次减去 2048。

### 10.4 MeanAD 精确定义

对当前三通道 RGB 输入的全部 H×W×3 个数值，计算一个共享均值和平均绝对偏差：

\[
m=\frac1N\sum_i x_i,\qquad d=\frac1N\sum_i|x_i-m|,
\]

\[
z_i=\operatorname{clip}\left(\frac{x_i-m+2d}{4d+\epsilon},0,1\right),
\qquad \epsilon=10^{-8}.
\]

- 不按通道分别计算统计量。
- 使用当前完整输入图像，不忽略零值，不传入有效区域掩码。
- 统计量以 double 累加，输出为 float32。
- 当 d≤epsilon 时输出全零。
- MeanAD 后使用 OpenCV COLOR_RGB2GRAY。
- SuperPoint 直接接收 [0,1] 的 float32 单通道图像，不再次除以 255。

验证损失和几何评价的有效掩码规则，与 MeanAD 自身的整帧统计规则分别保留。

### 10.5 已核对的真实 Raw 入口

这部分用于记录旧项目的实际实现，不新增本阶段真实数据评估。

| 入口 | 当前实现 |
|---|---|
| K60 | rawpy LINEAR demosaic；Raw 色彩空间；16 位；gamma=(1,1)；关闭自动亮度、自动缩放和白平衡；传入元数据黑白电平，随后按白电平归一化并编码 |
| Blackfly | OpenCV 双线性 demosaic；0–65520 映射到 uint16 的 0–65535；存储图像不加入白平衡、Gamma、曝光补偿或颜色矩阵 |

不同真实入口不共用一组物理黑白电平，进入特征提取阶段后调用相同的 MeanAD 函数。

### 10.6 基线测量与比较

学生和基线从同一份含噪 Bayer 分流，分别执行各自已经确定的预处理。

- 使用同一 COCO 验证清单、同一份噪声实现、同一几何关系和有效区域。
- 使用统一的特征数量预算、互为最近邻和几何估计规则。
- 验证集与基线配置固定后运行一次基线，保存逐图预测和全部分桶指标。
- 后续每个学生检查点报告学生指标、基线指标及差值。
- AUC 等百分比指标以百分点差值为主要比较方式，保留各档位结果。
- 若修改验证清单或基线预处理，重新运行基线。

基线中的裁剪、白平衡处理和 MeanAD 不移植到学生训练。当前对比不包含 LightGlue 或完整 SLAM 系统。

## 11. 日志、检查点与恢复

| 项目 | 经验配置 |
|---|---|
| 标量日志 | 每 20 次优化器更新 |
| 正式验证 | 每 2,000 次更新，训练结束额外验证 |
| 可视化 | 每次验证保存固定的 16 对图像 |
| 验证检查点 | 每次全部保留 |
| best | 指向主验证分数最高的检查点 |
| latest | 指向最新完整训练状态 |

日志至少包括学习率、ratio 上限与实际采样分布、三项原始及加权损失、有效监督数量、梯度范数及裁剪频率、分桶验证指标、吞吐和显存占用。

检查点在一次优化器更新完成后保存，包含学生及辅助头参数、BN 统计、优化器、所有调度状态、全局步数、随机状态、数据采样进度、完整配置和验证结果。严格恢复还需要处理 worker 随机状态。

不删除旧验证检查点，不以 best 替代全部历史保存。正式训练采用固定步数预算，不在噪声课程尚未完成时通过早停结束训练。

## 12. 实施时的小型试训

### 12.1 约 50 次更新的短检查

保留完整网络和分辨率，检查：

- 显存、吞吐与在线数据生成成本；
- 输入、教师、灰度目标和有效掩码的几何对齐；
- 对应点构造；
- 损失与梯度有限性；
- 梯度累积、保存和恢复。

另外使用最终 [1,100] 范围做少量独立的数值检查，确认最大倍率输入不会直接导致数值问题。

### 12.2 2,000 步配置校准

| 项目 | 配置 |
|---|---|
| 网络、尺寸、有效 batch | 与正式方案一致 |
| 训练源图像 | 固定抽取 2,048 张，增强每次重新采样 |
| 更新次数 | 2,000 |
| 学习率 | 200 步线性预热至 3e-4，随后保持 |
| ratio 上限 | 500–1,500 步由 1 增长到 16 |
| 损失权重 | 检测/匹配/灰度 = 1/1/10，全程固定 |
| 验证 | 每 500 步，使用正式验证清单的固定小子集 |

校准对象：

1. 实际 batch、梯度累积与数据生成吞吐。
2. 学习率、预热及更新稳定性。
3. 灰度辅助权重和梯度裁剪阈值。
4. 正式训练预算、验证规模与验证间隔的实际成本。

不把正式十万步课程机械压缩为两千步，不根据小试早期 AUC 判断最终低光性能或更换网络结构。

校准后固定正式配置，从随机初始化开始完整训练，不将小试的特殊课程混入正式训练记录。

## 13. 导出与效率评估

1. 根据固定 COCO 验证主指标选择检查点。
2. 复制模型，切换到评估模式。
3. 删除辅助灰度头。
4. 在每个 RepVGG 块内部融合 BN、3×3、1×1 与恒等分支。
5. 验证融合前后的检测与描述子输出数值一致性。
6. 在固定 COCO 协议下确认部署模型表现，测量效率。

融合利用固定 BN 运行统计，将各分支写成等价 3×3 卷积后相加。ReLU 保留在融合卷积之后。融合逐块进行，不将整个骨干合并为一层。

报告参数量、MACs，以及相同桌面 GPU、运行时、输入尺寸、batch 和 FP32 条件下的延迟。分别报告网络前向和包括预处理、关键点筛选、描述子采样的完整提取流程。

本阶段仍不增加 HPatches-raw、MID 或 SLAM 评估。
