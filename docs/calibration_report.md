## 范围与结论

已执行设计规定的 50 步检查、2,000 步配置校准、完整 1,536 对 COCO 基线和融合验证。正式 100,000 步训练未启动。独立 Conda 环境、官方资产、训练/恢复/验证/部署代码及配置均可运行；正式训练前的缓存/基线预检返回 `ready=true`。

校准用于核对数值稳定性、梯度、保存恢复和成本。本次校准模型全协议 H-AUC@5px 为 **1.388%**，MeanAD + SuperPoint 基线为 **60.739%**；校准模型明显落后，没有验证出性能提升。按设计要求，不依据这一早期结果更换网络或监督路线，正式训练效果仍未知。

## 经验参数决定

| 参数 | 设计值 → 正式配置 | 依据与决定 |
|---|---|---|
| 灰度权重 | 10→1（60k–80k）→ 不变 | 三项共享骨干梯度非零；200 步后加权灰度/检测加匹配梯度比中位数约 0.032，无持续灰度主导；保留原定权重。此比例来自首个共享卷积探针。 |
| 全局裁剪 | 5.0 → 5.0 | 共 151/2000 次（7.55%）；最后 500 步 0 次；后期裁剪前范数中位数 1.820。无需提高阈值。 |
| batch/累积 | 4 对 ×4 → 不变 | 实际 BN batch=8 个视角；有效 16 对；峰值 1.727 GiB。 |
| LR/预热 | 正式 3e-4 /2,000 → 不变 | 校准用设计规定的 200 步预热后恒定 LR；全程损失/梯度有限。正式单次余弦调度已通过边界测试，不混入校准课程。 |
| ratio 上限 | 正式 256 → 256 | 两次极端反向数值检查及固定验证输入有限；校准按设计只扩至 16。256 的长期训练适应与真实曝光范围尚未验证。 |
| 预算/验证 | 100k /每2k、256图 → 不变 | 已测得计算成本；完整协议固定，未为校准模型低分调整阈值或删样本。 |

没有依据小试 AUC 修改网络、添加损失、自动平衡或传入噪声条件。正式配置从随机学生初始化开始，不能以校准检查点作为正式预训练。

## 实测成本与部署

- 2,000 步加四次验证：约 6863.1 秒（1.906 小时），依据 TensorBoard 首步损失时间减首步耗时至末次验证事件，不包含环境初始化或后续融合导出。
- 日志更新耗时中位数 3.401 秒；最后 500 步 3.411 秒。按后期计算-only 线性外推 100k 约 94.7 小时（3.95 天），正式验证、负载变化及真实持续训练额外计入。
- RTX 5090、FP32、batch=1、4×240×320：595,105 参数、4,033,536,000 MACs，网络中位延迟 0.749 ms，含预处理和特征筛选 1.445 ms。该延迟来自校准检查点的固定 clean 样本，实际只检测到 46 个点，不能代表最终模型或 1,024 个点的提取成本。

## 工程修正与未验证项

- 原始耗时 13–14.5 秒来自早期检查；空闲 GPU 同设备分段测量为 6.02 秒。显式连续 NCHW 输入和对应点预分配/分块过滤使其降至约 3.38 秒；采样在 16 组完整尺寸输入上逐点一致。默认编译模式反而慢，未采用。
- Kornia pixel-coordinate warp 改为 align_corners=True；恒等及非平凡坐标场测试在 2e-4/1e-3 像素容差内通过。
- DN 域量化使用 ±0.5 DN；学生只归一化一次。保留用户选择的 full-DN 曝光序列。修正前的缓存/基线/试训归档于 `outputs/checks/before_geometry`、`before_quantization`，不能作为当前结果。
- CUDA/官方资产/已安装独立 Conda 环境已实际验证；另从 conda-forge 新建 rawfeat-clean 并按锁定依赖安装，复用本地 pip 缓存的原始 wheel，避免重复下载；CUDA 前后向有限、18 项测试通过、pip check 通过、正式预检 ready=true 且缓存身份一致。Torch 模块报告 2.12.1+cu130 /CUDA13.0，发行版元数据为 2.12.1，因此 requirements/environment 锁定发行版 torch==2.12.1，并在安装后实际验证 CUDA13.0。清洁环境证据见 outputs/checks/clean_environment_audit.json；安装日志为 clean_environment_install_cached.log。
- 未启动正式训练；最终性能、最佳训练检查点、真实 SLAM/未知曝光适应未验证。HPatches-raw、MID、LightGlue、FP16/INT8 等未纳入本项目。
